Purpose and scope

Tube Stash is a Chrome extension for saving and organizing YouTube videos, watching them from a side panel or YouTube tabs, resuming playback, and following selected channels. This policy covers the extension. YouTube and Chrome services have their own privacy practices, described below.

Data handled on your device

Tube Stash stores its library in your Chrome profile using Chrome extension storage:

  • Playlist names and identifiers, saved video IDs, URLs, titles, thumbnail URLs, ordering and added timestamps.
  • Followed channel IDs, names, URLs and image URLs; fetched publication titles, IDs and dates; seen/unread markers, check timestamps and errors.
  • Video playback positions, duration, watched markers and playback-speed preferences.
  • Preferences, selected playlist, and operational synchronization state, including random installation/replica identifiers, revision counters, deletion records, synchronization status and metadata-fetch attempt timestamps.

When you choose to save a current tab or import open tabs, Tube Stash reads available YouTube URLs and titles to create library entries. With optional YouTube and scripting access, its packaged content scripts read the YouTube video's identity, time, duration, playback state and speed to support progress, controls, handoff and autoplay. Once enabled, playback observation can operate in open YouTube watch tabs, including videos not yet saved in a playlist. It does not read Chrome's history database, messages, payment details, passwords or authentication tokens. It does not use the Chrome cookies API or collect your YouTube account identity.

Session-only playback coordination data is kept in Chrome session storage. JSON backup files are created only when you export them and read when you select an import. They contain library and playback data and are not encrypted by Tube Stash. Store and share them with care. Local extension storage is not separately encrypted by Tube Stash; protection depends on your device and Chrome profile security.

Network requests and third parties

Tube Stash has no developer-operated backend, telemetry, analytics SDK or crash-report service. The publisher does not receive your library automatically. The extension does make the following connections to provide its features:

  • YouTube metadata and feeds: with YouTube access, it requests public channel pages, Atom feeds and video oEmbed metadata over HTTPS. These requests disclose the requested video/channel ID or handle and ordinary connection information, including IP address, to YouTube/Google. Extension metadata/feed fetches omit credentials. Followed channels can refresh in the background while Chrome is running.
  • Images: displaying video thumbnails and channel images requests resources from YouTube/Google image servers, including i.ytimg.com, ggpht.com and googleusercontent.com. Image URLs identify the requested resource, and the servers receive ordinary connection information. These requests can occur when you open a library containing images, even if synchronization is off.
  • Playback: the embedded YouTube frame and its media resources connect to YouTube/Google. YouTube receives the selected video, playback requests and connection/device information. The extension supplies a referrer identifying the public extension ID, a temporary player-session marker, and a requested start position when resuming. The frame uses Chrome's credentialless mode: it runs signed out with ephemeral cookies/storage isolated from your normal profile session. Tube Stash does not provide YouTube login in this frame. A normal YouTube tab can use your profile's existing signed-in session and is governed by YouTube's usual privacy practices.
  • Optional Chrome synchronization: only when you enable the switch, Tube Stash writes playlist names and IDs, video IDs, channel IDs and their order, plus random replica identifiers and revision/deletion records, to chrome.storage.sync. Chrome can transfer that structure through Google's synchronization service according to your Chrome account/settings. Video titles, images, publication caches, playback positions, watched markers and speeds are not part of this synchronized payload. Details may subsequently be fetched from YouTube on a receiving device with permission. Tube Stash does not receive your Google credentials, account email or access tokens.

These necessary service requests mean that data does leave your device; local storage does not make YouTube playback or optional Chrome sync offline services. Google's handling of its services is described in the Google Privacy Policy and Chrome Privacy Notice. YouTube may display advertising; Tube Stash does not add its own advertisements or use library data for advertising.

Permissions and your choices

The extension uses storage for the library and optional sync, alarms for channel refresh/sync scheduling, active-tab access for saving the current video, the side panel for its interface, and context menus for saving YouTube links. A declarative network request rule sets the player referrer only on Tube Stash's own YouTube embedded-frame navigation; it does not intercept general browsing traffic.

YouTube/youtu.be site access and scripting are optional and requested for features such as importing YouTube tabs, fetching titles/channels, playback observation, embedded controls and autoplay. You can refuse them or revoke access in Chrome's extension settings; features that need that access will stop working. You can still manage stored entries and backups. Synchronization is off until enabled in the UI.

Retention, access and deletion

Local data remains in your Chrome profile until changed, removed, cleared through Chrome's extension storage controls or removed with the extension. You can inspect, edit and remove library entries in Tube Stash and export a JSON copy. Removing a playlist entry does not necessarily erase independent playback records or sync deletion records.

Disabling Tube Stash synchronization stops its synchronization work; it does not erase previously synchronized data, local copies, or data on other devices. Sync keeps deletion records to prevent stale devices restoring removed entries. There is no in-extension command to erase all synchronized replica records. Use Chrome's account/synchronization data controls to manage server-side data, and clear extension storage on each relevant profile if you want to remove local copies. Do not assume uninstalling from one profile deletes copies on other devices or Google's servers. Exported files remain wherever you saved them until you delete them yourself.

Limited Use and publisher access

Tube Stash's use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Data is used only for the disclosed video-library and playback features. The publisher does not sell user data, use or transfer it for personalized advertising, or use it to determine creditworthiness or for lending. Transfers initiated by the extension are limited to the services described above for these features. The publisher has no routine access to your stored library and does not allow humans to read it through a developer service. If you voluntarily send support material, send only what is needed and explicitly authorize review of that material.
